# Simple Interest Calculator

This project contains a shell script that calculates simple interest.

## Description

The Simple Interest Calculator computes the simple interest on a given principal amount based on the rate of interest and the time period provided by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Features

* Calculates simple interest accurately
* Accepts user input for:

  * Principal amount
  * Rate of interest
  * Time period
* Easy-to-use Bash script

## Usage

Run the script using:

```bash
bash simple-interest.sh
```

Enter the required values when prompted, and the script will display the calculated simple interest.
